# Car Racing Challenge
Reinforcement Learning (RL) has emerged as a powerful paradigm in artificial intelligence, allowing agents to learn optimal behaviors through interaction with their environment. In this project, we focus on applying RL techniques to the CarRacing-v3 challenge, an environment where an autonomous agent must navigate through a circuit. The environment has a continuous state and actions, making it a complex problem that requires the agent to balance exploration and exploitation while optimizing its driving strategy.

The main objective of this work is to design, implement, and evaluate different RL algorithms capable of achieving high scores in CarRacing-v3 while maintaining creative solutions. For that, we explore different approaches and analyze their performance in terms of learning efficiency, stability, and generalization to new tracks.
